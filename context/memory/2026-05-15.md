- **Full email separation, not alias-domain.** Two $7/mo Workspace seats (victor@, hako@). Cost: $14/mo total for TPT side. Justifies separate inbox identity for cofounder.
- **Display name convention for generic addresses:** "Victor & Hako at The Primary Trail" on hello@ and info@. Requires actual cofounder visibility into those inboxes to be honest. Pattern not yet wired — open thread.
- **DBA over separate LLC.** Saves entity formation cost + ongoing entity overhead. Trade-off: TKJ ↔ TPT liability is shared (no inter-brand shield). Mitigation: tight engagement-letter scope + TKJ E&O policy amended to cover TPT as named insured.
- **TKJ DNS stays at Squarespace for now.** Migration to Vercel deferred to coincide with TKJ website rebuild (future project). Don't decouple DNS from hosting prematurely.
- **SPF/DKIM/DMARC done in single sweep across all 3 brands.** Sequential discipline saved time and ensured consistent recipe. Recipe: SPF (manual TXT) + DKIM (Google admin generate → DNS TXT add → admin "Start authentication") + DMARC (manual TXT with `p=none` for monitoring).
- **Lombardi quote contained to attributed citation.** Brand-voice rule against "win" remains intact in H1 and lead; the quote's two "win" instances live in a visually subordinate `<cite>` block. Future SOUL.md update should codify the external-epigraph convention.
- **GitHub Actions $0 budgets** on icrumba account confirmed in place across all five products (Codespaces, Packages, Actions, Git LFS, Premium Request SKUs). No billing risk from approaching quota.
